# 📱 **ANIME_VERSE-D**

Aplikasi **Anime Verse** adalah aplikasi mobile sederhana berbasis Flutter yang menampilkan berbagai informasi terkait anime. Aplikasi ini dibuat sebagai proyek pembelajaran untuk memahami UI Flutter, navigasi, konsumsi API, dan pembuatan release APK.

---

## 🚀 **Fitur Utama**

* 🔍 **Pencarian Anime**
  Cari anime berdasarkan judul.

* 📄 **Detail Anime**
  Menampilkan sinopsis, genre, rating, dan informasi lainnya.

* ⭐ **Favorite Anime**
  Menyimpan anime favorit pengguna (local storage / Firestore jika tersedia).

* 🎨 **UI/UX Sederhana & Modern**
  Menggunakan Material Design + animasi ringan.

---

➡️ **APK tersedia pada tab Releases:**
Buka: **`Releases > Download app-release.apk`**

## 🛠️ **Tech Stack**

* **Flutter** (Dart)
* **State Management:** Provider / setState
* **API:** Jikan / Custom API (sesuai implementasi)
* **Local Storage:** SharedPreferences / Firestore
* **Build Tool:** Gradle

## ⚙️ **Cara Menjalankan Project**

Pastikan Flutter sudah terinstall:

```sh
flutter --version
```

### 1. Clone repository

```sh
git clone https://github.com/Divay11/ANIME_VERSE-D.git
```

### 2. Masuk folder project

```sh
cd ANIME_VERSE-D
```

### 3. Install dependencies

```sh
flutter pub get
```

### 4. Jalankan aplikasi

```sh
flutter run
```

---

## 📦 **Build APK**

Untuk membuat APK release:

```sh
flutter build apk --release
```

Output berada di:

```
build/app/outputs/flutter-apk/app-release.apk
```
